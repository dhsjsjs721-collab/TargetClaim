# Land of Losers Wiki

Static player documentation. GitHub Pages: Settings → Pages → Deploy from a branch → gh-pages / (root). No Minecraft server process, database, or external runtime needed. All custom item images are embedded from the existing guide. Edit pages and search-index together when recipes change. Draft roadmap is explicitly not released. Verified game status as of 27 Nov 2026. This branch contains only website files; main and plugin build branches are untouched.

Recipe textures: vanilla Minecraft 26.3 assets from https://github.com/InventivetalentDev/minecraft-assets/tree/26.3 (Mojang assets); custom item artwork preserved from the guide. Ender chest uses its entity texture atlas; custom items without distinct art use their base/model item texture.
