# TargetClaim 1.2.0

Custom Paper server protection plugin. One private territory per player.

- Special TARGET block crafted from **3 paper + 6 amethyst shards**.
- Five sizes: 16x16, 40x40, 80x80, 120x120, 160x160.
- Upgrades: 23 amethyst, 64 amethyst, 3 netherite scrap, 1 dragon egg.
- Team-based access by scoreboard team color.
- /p, /p border, /p remove, /p give <player>.
- Private target is **never returned as an item** when destroyed or removed.
- No special restrictions on fire, explosions, liquids, hoppers, pistons (besides handling the core).

## Build
Open GitHub Actions -> Build plugin JAR. Download the successful artifact, then test the JAR on a separate Paper test server. This project has not yet been validated in-game.
