Установка и обновление

Игрокам

Minecraft 26.3, Java 25, Fabric Loader 0.20.1 и Fabric API 0.166.2+26.3. Помести LandMinimap-Fabric-0.4.0.jar в mods/. Прими ресурспак сервера. При несовпадении версий сверяй зависимости в fabric.mod.json.

Администратору

Установи LandMinimap-Bridge-0.4.0.jar в plugins/. Обнови MinecraftUnified и UnifiedAuth, сохрани папки данных, сделай резервную копию и полностью перезапусти сервер. Не оставляй дубликаты JAR. Проверь рецепты и совместимость античита.

Авторизация и защита

UnifiedAuth 1.6.4 поддерживает опциональный PIN с доверенной сети; по умолчанию пароль не пропускается. На offline-сервере такой режим требует явного разрешения и снижает безопасность. UnifiedAntiESP 3.6.0 защищает позиции игроков; EntityESP был отключён из-за невидимых мобов.
